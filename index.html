Deep learning + XAI

  • 1D-CNN kernels 3/5/7, Bi-LSTM 2×80, dropout 0.3, window L=250
  • EWMA span 30, nonparametric threshold 2.5σ to 10σ, no test labels
  • Pruning of clusters with under 13% error drop-off; Integrated Gradients per channel

RAG

  • Qdrant, cosine similarity over NASA incident docs, Telemanom reports, failure logs
  • Groq / Gemini failover for the LLM layer

Security

  • API key auth, RBAC, token-bucket rate limit, CORS isolation, input sanitization
  • Idempotent payload dedupe, pydantic-settings and Docker secrets

Docker

  • Multi-stage Dockerfile; compose: API + Qdrant + Grafana

Limitations

This page's demo is a JavaScript simulation, not the PyTorch model. Real results need the NASA SMAP/MSL data and training. Thresholds vary per channel, LLM diagnoses are hypotheses to verify, and safety-critical actions always need human approval. Not flight-qualified.
